---
title: "Claude Code 配置"
---

将下列对象合并到 Claude Code 的 `settings.json`。默认模型为 `gpt-5.6-sol`。

## 配置文件路径

| 系统 | `settings.json` 路径 |
| --- | --- |
| macOS / Linux | `~/.claude/settings.json` |
| Windows | `%USERPROFILE%\.claude\settings.json` |

如果文件已经存在，请合并 `env` 和 `model` 字段，不要直接覆盖其他 Claude Code 配置。

## settings.json

```json
{
  "env": {
    "CLAUDE_CODE_ATTRIBUTION_HEADER": "0",
    "CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC": "1",
    "ANTHROPIC_AUTH_TOKEN": "sk-your-rex-key",
    "ANTHROPIC_BASE_URL": "https://ai.j1ao.vip/"
  },
  "model": "gpt-5.6-sol"
}
```

## 注意事项

- Anthropic 格式的 `ANTHROPIC_BASE_URL` 必须以 `/` 结尾，并且不能包含 `/v1`。
- 鉴权字段使用 `ANTHROPIC_AUTH_TOKEN`。
- 不要将包含真实 API Key 的 `settings.json` 提交到 Git 仓库。
