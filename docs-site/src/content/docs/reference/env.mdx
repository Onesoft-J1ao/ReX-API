---
title: "环境变量"
---

| 变量 | 示例 | 说明 |
| --- | --- | --- |
| `REX_API_KEY` | `sk-...` | ReX API 密钥。 |
| `REX_BASE_URL` | `https://ai.j1ao.vip` | Router 根地址，不含 `/v1`。 |
| `OPENAI_API_KEY` | `sk-...` | OpenAI 兼容客户端常用密钥变量。 |
| `OPENAI_BASE_URL` | `https://ai.j1ao.vip/v1` | OpenAI 兼容客户端常用 Base URL。 |
| `ANTHROPIC_API_KEY` | `sk-...` | Anthropic 兼容客户端常用密钥变量。 |
| `ANTHROPIC_BASE_URL` | `https://ai.j1ao.vip` | Anthropic 兼容客户端常用 Base URL。 |

## 使用建议

- 将真实密钥保存在终端环境、`.env`（已加入 `.gitignore`）或 CI Secret 中。
- 不要在示例配置、日志、截图或问题反馈中暴露完整 API Key。
- `OPENAI_BASE_URL` 包含 `/v1`；`REX_BASE_URL` 是根地址。不要混用这两个值。
